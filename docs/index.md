# SAR Drone Build Log

I'm Joseph Kim, a UIUC sophomore and a beginner in AI. This site documents an **aerial casualty-location proof of concept** I'm building for the Cozad New Venture Competition.

The project has two chapters:

- **[Chapter 1: Search Path](chapter-1-search-path/index.md)** plans a "lawnmower" flight path so the drone photographs the whole search area with no gaps.
- **[Chapter 2: Person Detection](chapter-2-person-detection/index.md)** scans those photos and flags likely people **for a human to review**.

!!! warning "Prototype, not a product"
    These tools are early experiments. Read the [Limits](limits.md) page before drawing conclusions.

Updates and lessons learned go in the [Blog](blog/index.md). New terms are defined in the [Glossary](glossary.md).
